# West Annex fixture provenance

The WebVTT scripts, chat messages, glossary, and scoring annotations were written for Roxi's fictional logistics drill. They describe invented participants and events. The public fixture includes these authored files and the repository includes the audio generation script.

The script reads the authored WebVTT and synthesizes two WAV files with the Microsoft David Desktop and Microsoft Zira Desktop voices already installed in Windows. Generate them from the repository root as described in the [local setup](../../README.md#run-the-local-app). The generated recordings and Windows voice assets are outside the public Git history. The redistribution terms for recordings produced by these desktop voices were unverified during the publication review. [Windows software license terms](https://www.microsoft.com/content/dam/microsoft/usetm/documents/windows/11/oem-%28pre-installed%29/UseTerms_OEM_Windows_11_English.pdf)

Roxi's source and authored fixtures are publicly viewable through GitHub. A separate open-source license has yet to be selected. External dependencies and models are obtained separately under their respective terms.
